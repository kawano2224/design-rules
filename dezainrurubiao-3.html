GitHub用コード（Supabase連携版）

この形で確定したデザインを、みんなで編集できる本番サイトにするためのコードだよ。下のコードをそのまま使うと、保存先がSupabaseにつながるよ。

  1. Supabase でプロジェクトを作る（無料枠でOK）
  2. Supabaseの SQL Editor に、下の「① SQL」を貼って実行する
  3. 「② index.html」をダウンロードして、冒頭の SUPABASE_URL と SUPABASE_ANON_KEY に、自分のプロジェクトの値を入れる（Settings → API で確認できるよ）
  4. そのファイルをGitHubのリポジトリに index.html として置いて、Settings → Pages で公開する
